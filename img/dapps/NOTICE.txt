dApp icons

Each <guid>.<ext> is the dApp's own icon, extracted unchanged from the pinned mainnet package that
the BEAM desktop wallet bundles, BeamMW/beam-ui (ui/apps/mainnet/*.dapp), licensed under the
Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0), which is compatible with this
project's GPLv3. The packages are pinned by SHA-256 in src/lib/dapps/catalogue.js; the path of
each icon is the one its manifest.json names.

They ship inside the signed release so the dApps list can show an app before it is downloaded,
without fetching anything: an icon URL would tell its server who is browsing which dApps.

The packages themselves are not part of the release: they bundle third-party fonts whose licences
do not clearly allow redistribution. BEAM Campfire downloads a package from BEAM's GitHub the first
time it is opened and refuses it unless its size and SHA-256 match the pin.
